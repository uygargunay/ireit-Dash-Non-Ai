# Visual references

The supplied condensed summary and eight full-page screenshots define the intended IREI visual language:

- navy left navigation;
- blue selection and semantic status accents;
- white dashboard cards;
- executive portfolio KPIs;
- evidence-based status and risk indicators;
- financial capacity and debt visuals; and
- mission, impact and affordability sections.

The web UI in `src/IreiMvp.Web/wwwroot` applies this language across eight workflow pages. It does not hard-code screenshot metrics or reproduce confidential formulas in the participant view.
