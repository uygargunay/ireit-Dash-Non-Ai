# Visual references

These five supplied images define the intended IREIC visual language:

- navy left navigation;
- teal selection and status accents;
- white dashboard cards;
- executive portfolio KPIs;
- readiness and risk indicators;
- financial capacity and debt visuals; and
- mission, impact and affordability sections.

The web UI in `src/IreiMvp.Web/wwwroot` applies this language without reproducing raw confidential methodology or formulas in the participant view.
